## 📝 ENUNCIADO DEL EJERCICIO

Desarrollar una **aplicación móvil en Android Studio** que implemente las siguientes funcionalidades:

### 1. Splash Screen
Tener una actividad de inicio o de arranque también conocida como **splash screen**, que es usada para mostrar al inicio de una aplicación el logo de la App, antes de que el usuario empiece a usarla.

### 2. Login
Tener una actividad de **inicio de sesión o login**, en la cual se ingresará y validará el nombre de usuario, el cual deberá de tener un **formato válido de correo electrónico**, y una **contraseña** de longitud **no menor a 8 caracteres** y en **formato alfanumérico**.

### 3. Guardar credenciales
La actividad de inicio de sesión deberá de tener un elemento de la clase **checkbox** o preferiblemente un botón del tipo **"Chip"** para activar el guardar el usuario y contraseña usando **SharedPreferences**.

### 4. Registro de usuario
La actividad de inicio de sesión deberá de permitir dar de alta el usuario (botón o enlace de **"Registrarme"**) utilizando los campos:

| Campo | Validación |
|---|---|
| a. Correo electrónico | Formato válido de email |
| b. Nombre completo | Longitud ≥ 7 caracteres |
| c. Contraseña | ≥ 8 caracteres, alfanumérica |
| d. Confirmar Contraseña | Debe coincidir con la contraseña |

> ⚠️ **Importante:** las claves deberán de **encriptarse**. Si se guardan en texto plano, **se anularán los criterios de evaluación 1 y 2**.

### 5. Persistencia del registro
El nuevo registro de usuario se deberá de guardar en una base de datos **FireStore** y en local en una base de datos **SQLite** (puede usar la librería **Room**).

### 6. Home + Perfil
Una vez ingresado y validado el usuario en la aplicación, se deberá de mostrar la actividad de **Home**, la cual deberá de contener como mínimo una **Toolbar con un menú** en el cual se mostrará la opción de **Perfil del usuario** y donde se podrá actualizar el nombre del usuario y la contraseña (solicitando confirmación).

### 7. Actualización de perfil
La actividad de actualizar perfil deberá de realizar la actualización en la **base de datos en la nube y en local**.

### 8. CRUD de entidad de negocio
La App deberá de realizar las **operaciones CRUD** de una de las clases de persistencia que se gestionen en su contexto de negocio, como por ejemplo las operaciones CRUD de una cita, un proveedor, un cliente, un pedido, una reserva, etc. La persistencia de los datos debe de ser tanto en **local como en remoto (Firebase)**.

### 9. Sincronización offline
En todo el diseño se deberá de considerar la **sincronización de base de datos en nube y local**. De tal manera que si no es posible actualizar la base de datos en nube se deberá de manejar un **estado de actualización pendiente** en la base de datos local que posteriormente deberá de intentarse de nuevo en la ventana de perfil.

### 10. Mapa
La App deberá de mostrar una actividad o fragment que muestre un **punto predefinido en un mapa**, que corresponda a la dirección de comercio o negocio al cual hace relación su proyecto.

## 📊 CRITERIOS DE EVALUACIÓN

| Criterio | Funciona completamente | No funciona completamente |
|---|:---:|:---:|
| La aplicación se ejecuta con su actividad de inicio o bienvenida (splash screen) | **5%** | **0%** |
| La aplicación ejecuta correctamente las actividades de inicio de sesión con las opciones de registrarse, guardar usuario, e iniciar sesión, con sus respectivas validaciones. Almacenando los datos de usuario tanto en local como en la base Firebase | **15%** | **5%** |
| La aplicación realiza las operaciones CRUD de una entidad de persistencia (como, por ejemplo, una cita, un pedido, un cliente, un proveedor, etc.) en la base de datos Firebase y en la base de datos local | **40%** | **10%** |
| La aplicación puede quedarse sin internet y actualizar la información de la base de datos en local y posteriormente sincronizar la base de datos en la nube | **25%** | **0%** |
| La App muestra un punto de referencia en un mapa integrado de Google, que haga referencia a un punto geográfico vinculado a su proyecto (oficina, local, etc.) | **15%** | **0%** |
